# 글 템플릿

모든 초안 머리:

```markdown
## <채널> — <언어>
- 작성 페이지: <URL>
- [ ] 규칙/플레어 확인  - [ ] 첨부: <GIF/영상 파일>  - [ ] 게시 후 2시간 댓글 대응
```

## 공통 뼈대

1. **훅**: 문제 또는 결과 한 줄 ("Blender에서 리깅에 30분 → 클릭 한 번")
2. **데모**: GIF/영상
3. **무엇**: 핵심 기능 3개
4. **왜**: 만든 이유 1~2문장(개인 경험)
5. **링크 + 요청**: "피드백 환영" / "써보고 의견 주세요"

## X 스레드 (영어, 3~4개)

```text
1/ <결과 중심 훅, 1문장>. <짧은 설명>
[데모 영상]

2/ What it does:
• <기능1>
• <기능2>
• <기능3>

3/ Why I built it: <1~2문장>

4/ Free & open source → <링크>
#<태그1> #<태그2>
```

## LinkedIn (한국어 또는 영어)

```text
<공감 가는 문제 한 줄>

<그래서 만든 것 1문단>

이번에 만든 <이름>은:
✔ <기능1>
✔ <기능2>
✔ <기능3>

<만들면서 배운 점 1문단>

👉 <링크>
#<태그>
```

## Reddit (영어)

```text
제목: I made <이름>, a <무엇> that <결과> [<엔진/툴 이름>]

본문:
<데모 영상 업로드>

Hi! I kept running into <문제>, so I built <이름>.

- <기능1>
- <기능2>
- <기능3>

It's free/open source: <링크>
Works with <버전 호환>.

Would love feedback, especially on <구체적으로 의견 받고 싶은 부분>.
```

## GeekNews (한국어)

```text
제목: Show GN: <이름> - <한 줄 설명>

<무엇을 하는 도구인지 2~3문장>

- <기능1>
- <기능2>
- <기능3>
- <기술 스택/라이선스>

<만든 계기 1문장>
```

## Show HN (영어)

```text
제목: Show HN: <Name> – <one-line description>
URL: <바로 써볼 수 있는 링크>
첫 댓글: <동기 2문장> <기술 스택> <한계와 다음 계획> <피드백 요청>
```

## 포럼 릴리스 글 (Blender Artists / Unity Discussions / Godot Forum)

```text
제목: [Released] <이름> <버전> - <한 줄 설명>

<데모>
## Features
## Installation
## Compatibility (<버전>)
## Links (문서·저장소·다운로드)
## Changelog
```
