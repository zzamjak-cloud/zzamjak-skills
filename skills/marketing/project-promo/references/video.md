# 영상 기획

사용자는 얼굴·목소리 없이 만드는 것을 기본으로 한다: **화면 녹화 + 큰 자막 + 배경 음악**.

## 쇼츠 (Shorts·TikTok·Reels 공용, 9:16)

구조 (20~40초):

| 구간 | 길이 | 화면 | 자막 |
|---|---|---|---|
| 훅 | 0~2초 | 가장 화려한 결과 또는 전/후 비교 | "<N초 만에 X>" / "이거 클릭 한 번이에요" |
| 문제 | 2~5초 | 기존의 번거로운 방식(빠르게) | "원래는 이렇게 오래 걸림" |
| 시연 | 5~25초 | 실제 사용 과정(2~4배속, 클릭 지점 확대) | 단계별 2~4단어 |
| 결과 | 마지막 3~5초 | 완성 결과 정지 화면 | 이름 + "무료 / 링크는 프로필" |

- 첫 프레임이 썸네일이다. 결과물로 시작한다.
- 자막은 화면 중앙~상단 2/3 영역(하단은 UI에 가려짐). 한 번에 한 줄.
- 언어: 영어 자막이 도달 범위가 넓다. 한국어판은 따로 만든다.
- 음악: 각 플랫폼 앱의 라이브러리 음악을 쓰거나 저작권 무료 음원.

video.md에 쓸 것: 장면별 표(위 형식), 촬영 목록(어떤 화면을 몇 초 녹화할지), 플랫폼별 캡션과 해시태그 3~5개, 썸네일 문구.

## 녹화와 변환

1. macOS `Cmd+Shift+5`로 해당 창 또는 영역 녹화(.mov).
2. 세로 변환: `scripts/make_vertical.sh <입력> <출력.mp4> [시작초] [길이초] [배속]`
   - 1080x1920, 원본을 가운데에 두고 배경은 흐린 확대본으로 채운다. 오디오는 제거한다(음악은 앱에서 입힘).
3. 자막은 CapCut·YouTube 편집기·플랫폼 앱에서 넣는다(가장 빠름).
