# 전설 장면 배치(.blend) — 사용자가 블렌더에서 소품 자리를 조정

- 장면 파일: `art_src/legend_scenes/<전설>.blend`(전설마다 하나, 막·장소마다 Blender 장면 하나). 모델 카탈로그의 「보기: 전설 장면」 카드에서 Blender로 열고(그 막 장면으로 열림) 「게임 적용」한다.
- 「소품(조정)」 모음의 빈 오브젝트(모델 원본 .blend 를 링크해 인스턴스로 보여 줌)를 옮기기·돌리기·크기 바꾸기 → `python3 tools/legend_layout/apply_layout.py apply <전설>` → `scripts/core/legend_layout.gd`(자동 생성, 바뀐 것만) → 게임 `LegendTheater._layout` 이 대본 자리 대신 쓴다. 자동 자리로 되돌리면 덮어쓰기도 지워진다. 「참고」 모음(배우 첫 자리·흩뿌린 자연물·바닥)은 적용되지 않는다. 「연출 소품(잠김)」 모음은 대본 비트가 가리키는 장면 소품(불태우기·쓰러뜨리기·바라보기·치우기·도중에 나타나기)이라 선택·삭제를 막는다(`dump_layout.gd` 의 `_staged`, 지움 표시는 무시).
- 지우기: 장면에서 삭제(X)하거나 숨기면(H) `{"del": true}`로 게임에서 빠진다(장면 소품은 대본이 가리키므로 모델만 감춘다). 다시 만든 장면 파일에는 숨김으로 들어오고, 숨김을 풀면 되살아난다.
- 열쇠: 장소 세트 소품 `set:<장소>:<번호>` · 실내 살림 `room:<장소>:<칸>` · 벽 토막 `wall:<장소>:b<번호>`(뒤)·`l<번호>`(왼쪽) · 장면 소품 `<전설>:<막>/<키>[#n]`. 대본 props 배열의 순서를 바꾸거나 중간에 끼워 넣으면 번호가 밀리므로 끝에 더한다.
- 대본에 소품·장소를 더하거나 뺐으면 `apply_layout.py build [전설...]`로 장면 파일을 다시 만든다(기존 파일의 손댄 자리를 먼저 적용한 뒤 게임 무대를 내보내 새로 만든다 — `dump_layout.gd` → `build_scene_blend.py`).
- 장면 파일은 사용자가 고치는 원본이다. 손댄 자리가 적용되지 않은 채로 새로 만들어 덮어쓰지 않는다(build 는 항상 apply 먼저).
